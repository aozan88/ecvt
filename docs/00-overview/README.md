# 00 — Overview

## What is ECVT?

ECVT (Edge Case Validation Toolkit) is an **AI Quality Engineering Platform**.
It validates existing AI-based or classic software systems — pre-production
and post-production — by generating edge cases, verifying acceptance
criteria, tracking regression, and producing reports for different audiences.

## What ECVT is NOT
- Not an AI Dev Team (MetaGPT, OpenDevin, ChatDev).
- Not an Agent Builder framework (CrewAI, AutoGen).
- Not an LLM wrapper.

## Why it matters
The AI Quality Engineering category (Patronus, Galileo, Braintrust, Arize
Phoenix, LangSmith) is growing, less crowded, and enterprise-critical. ECVT
differentiates by serving **three audiences** (Dev / Business / QA) with a
**domain-agnostic plugin** architecture.

## One-line pitch
> A Patronus/Galileo-style AI Quality Engineering platform that serves three
> audiences (Dev/Business/QA) with a domain-agnostic plugin architecture.
