# /retro — Weekly Reflection

Guide me through the weekly retro (Sunday, 30 min):

1. Read this week's DoD from Master Plan v6.2.
2. Ask me which DoDs completed vs slipped.
3. Ask which agent(s) advanced, which tests passed.
4. Ask CCA-F progress (hours of course + cookbook, unclear topics).
5. Ask AIPM cheatsheet usage count.
6. Ask energy level 1-10.
7. If energy < 7 for the 2nd week in a row, suggest scope reduction.
8. Write the retro to `docs/10-roadmap/retros/YYYY-MM-DD.md`.
9. Update the Etap 2 backlog if new items emerged.
