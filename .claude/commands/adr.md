# /adr — New ADR Draft

Create a new Architecture Decision Record:

1. Find the next ADR number in `docs/11-decisions/` (highest + 1, 4 digits).
2. Ask me for the decision title and short context if not provided.
3. Draft the file `docs/11-decisions/NNNN-<kebab-title>.md` using the ADR
   format in `docs/conventions.md` (Status/Date/Context/Decision/
   Consequences/Alternatives Considered).
4. Keep it to max 1 page. Set Status = Accepted and Date = today.
5. Do NOT modify existing Accepted ADRs.
